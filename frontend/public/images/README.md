# Images du site

Déposez ici vos photos (format JPG ou WebP, environ 1600 px de large, < 400 Ko),
puis renseignez leur chemin dans `src/config/site.ts` :

| Clé `site.images` | Fichier suggéré          | Utilisation                                 |
| ----------------- | ------------------------ | ------------------------------------------- |
| `hero`            | `/images/hero.jpg`       | Grande image de la page d'accueil (4:3)      |
| `printing`        | `/images/impression.jpg` | Visuel du service d'impression               |
| `formatting`      | `/images/mise-en-forme.jpg` | Visuel de la mise en forme / secrétariat  |
| `binding`         | `/images/reliure.jpg`    | Visuel reliure et agrafage                   |

Tant qu'aucune image n'est renseignée, une illustration vectorielle intégrée est affichée.
Utilisez uniquement des images dont vous détenez les droits.
